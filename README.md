# StreamGuard for FiveM

StreamGuard inventories FiveM resources and reports known texture payload costs and coverage gaps. It can create and verify separate copies using supported diagnostic DDS transforms.

Download the [Windows x64 installer](https://github.com/ToastyOfficial/StreamGuard/releases). Installed copies check the signed manifest on the versions branch for updates.
